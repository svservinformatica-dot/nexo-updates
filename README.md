# Nexo — Atualizações oficiais

Canal público de distribuição do aplicativo **Nexo**, desenvolvido pela **SV Serv Informática**.

O código-fonte do Nexo permanece em um repositório **privado**. Aqui serão publicados somente arquivos APK Android assinados e informações das versões; não serão armazenados tokens, dados de usuários, chaves de assinatura ou código do aplicativo.

## Instalação e atualizações

O Nexo verificará atualizações pelo GitHub Releases, com intervalo automático mínimo de seis horas e opção de busca manual no painel lateral. A instalação ocorre mediante confirmação do Android.

Consulte [Releases](../../releases) para as versões disponíveis. Não instale APKs obtidos de outras fontes.

## Formato de lançamentos

- Tag de versão: `vX.Y.Z-alpha`
- APK assinado: `Nexo-VX.Y.Z-Alpha.apk`
- Notas da versão: `[correção]` ou `[novidade]`, seguidas de descrição breve
- Publicação somente após validação e aprovação

Site institucional: https://svservinformatica.pages.dev/
